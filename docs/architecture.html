Factory Inventory Management System

Full-stack demo: a Vue 3 single-page app talking to a FastAPI service that serves in-memory data loaded from JSON files. No database.

Data flow

  1. User sets filtersTime period, warehouse, category and order status are held in a shared singleton in composables/useFilters.js.
  2. View requests dataThe view calls a method on api.js, which drops "all" values and builds query params.
  3. FastAPI handles the requestThe route in main.py runs apply_filters / filter_by_month (quarters such as Q3-2025 expand to months).
  4. Data comes from memoryLists loaded from server/data/*.json by mock_data.py at startup are filtered in place; nothing is written back.
  5. Response is validatedPydantic response_models check the shape and the JSON goes back to the browser.
  6. UI derives and rendersRaw results sit in refs; totals, charts and status badges are computed properties.

Observations from the code

  • api.js calls /api/tasks and /api/purchase-orders (create / toggle / delete), but no matching routes exist in main.py, which only defines GET endpoints.
  • views/Backlog.vue exists but is not registered in the router.
  • The API base URL is hard-coded to http://localhost:8001/api and CORS allows all origins; fine for a demo, not for deployment.
  • Dashboard.vue (about 1,270 lines) and Spending.vue (about 850) hold most of the UI logic.
